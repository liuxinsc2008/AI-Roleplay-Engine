## 用 GitHub Desktop 上传

1. 打开 GitHub Desktop → **File → New repository**
   - **Name**：`psychological-sovereignty-engine`（或任意英文名）
   - **Local path**：选一个空目录的**上一级**
   - **Initialize with a README** ⇒ **取消勾选**
   - 点 **Create repository**

2. 打开那个新建的仓库文件夹，把**本文件夹里的所有内容**（README.md / LICENSE / .gitignore / assets / docs）
   **复制进去**（连同隐藏的 .gitignore）

3. 回到 GitHub Desktop ⇒ 左下角填 Summary（如 `初版`）⇒ **Commit to main**

4. 点 **Publish repository**
   - **⛔ 取消勾选 `Keep this code private`**（否则是私有）

5. 完成。仓库地址形如 `https://github.com/你的名字/psychology-...`
