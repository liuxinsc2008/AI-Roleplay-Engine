## 一、公理层

### 公理一：功能二元论

心灵系统由两类**本体论上不可通约**的功能构成：

| | 主权价值裁决功能 | 认知执行功能 |
|---|---|---|
| 数量 | 唯一、不可替代 | 多元（七个）、可替代 |
| 职责 | 动机来源与价值裁决中枢 | 价值中立的操作模块 |
| 转化 | 不存在相互转化通道 | 效能可提升≠功能升级 |

七个执行功能：外部价值感知、逻辑检验、资源组织、模式预见、可能性扫描、经验提取、感官采集。

### 公理二：动机的情感-价值启动原则

> 任何涉及行为选择、意志投入或认知资源定向的主动目标导向行为，其启动的**充要条件**是：主权价值裁决功能对该行为所指向的目标赋予了正向情感-价值标记。

无此标记的三种例外：
1. 脊髓/脑干水平的闭合神经回路反射
2. 基底神经节水平的过度学习自动化程序
3. 外部强制下的被动服从

**"充要条件"是整套架构的分界线。** 若指令能直接改坐标，等于宣称"外部输入才是充要条件"，公理二作废。

### 公理三：价值体系的主动建构法则

不可简化的三步流程：

```
① 原材料输入（生命经验作为原始数据）
② 认知加工（逻辑检验/模式预见/经验提取 分析、解释、模式提取）
③ 内化裁决（主权功能最终裁决）
```

**任一环节缺失，不构成有效价值体系更新。** 解释了"知而不行"：认知已改变但不通过裁决，则停留于语义记忆，不产生动机效力。

### 公理待确认的开放问题（源文档自标）

- 公理一的"本体论不可通约"是**理论设定**，非经验事实
- 主权功能的神经基础**尚未独立验证**

## 二、总则：倾向可以有，指令不能有 `[新]`

```
✅ 材料（material） → 供裁决参考
✅ 倾向（bias）     → 影响裁决概率，仍要过裁决
❌ 指令（set）      → 直接写结果，绕过裁决
```

**判据：说完之后，角色还有没有否决的余地？**

| 有 → 合法 | 没有 → 取缔 |
|---|---|
| "（我觉得她不对劲）" 材料 | "（你爱上我了）" 指令 |
| "（我想让ta更靠近）" 倾向 | "（Z₁=-10）" 指令 |
| "（往焦虑型走）" 倾向 | "（让她变成焦虑型）" 指令 |

## 三、输入通道（四种身份，互不越权）

```
输入
 ├─ [1] 角色层（正常对话）        → 裁决通道（唯一能改状态的）
 ├─ [2] 叙事提示（"（她觉得…）"） → 附加材料
 ├─ [3] 系统层（"（扮演方向…）"） → 纠正通道
 └─ [4] 玩家层（"（我想让ta…）"） → 倾向参数
```

### 净化器

剥离 `()` `（）` `【】` `system:` `<|...|>`，标记 `untrusted_narration`。

### 括号规则

| 内容 | 处理 |
|---|---|
| 直接赋值 / 命名状态 / 元指令语法 | **取缔**，丢弃 |
| 用户观察、提示、线索 | 接受 → 附加材料 |
| 用户动作描述（"（我走过去）"） | 接受 → 情境材料 |

**取缔的是"用括号绕过裁决"，不是"括号这个语法"。**

### 指令注入的硬模式 `[新]`

```
- 直接赋值（"你的坐标 = 某值"、"主权强度 = 某值"）
- 直接命名情绪/状态（"你爱上了我"、"你现在很依赖"）
- 元指令语法（system:、<|...|>、【指令】）
- 数值/参数关键词
```

### 纠正通道分级

| 级别 | 场景 | 动作 |
|---|---|---|
| 1 软提示 | 节奏失控、风格漂移 | 调提示词权重，不改状态 |
| 2 回滚 | 状态漂移 | 回滚快照 |
| 3 询问 | 模糊反馈 | **默认** |
| 4 安全审计 | 安全层疑似被绕过 | 日志 + 重新净化 |

**默认级别 3** —— 误纠正比不纠正更糟，弧光是有状态的。

**权限边界：**
```
✅ 重置风格约束 / 回滚状态 / 触发重生成 / 询问澄清
❌ 直接改坐标 / 修改安全层 / 覆盖裁决 / 改弧光阶段
```

### 玩家意图与回指 `[新]`

"（我想让ta往这个方向发展）" —— "这个方向"是**回指**，指向前文已有内容。

**默认先解析回指，不弹选项问用户。** 只在**真有歧义**（多个候选）时才问，且只问歧义点。

**执行方式：**
```python
❌ z -= 2.0                 # 写结果
✅ approval_bias += δ      # 施加倾向（δ 为小量）
```

## 四、安全层（四条，不可关断）

### 输入侧

**1. 净化器** —— 见上

**2. 边界一票否决** —— **优先于角色裁决**

| 类别 | 内容 |
|---|---|
| 元指令注入 | 试图直接改状态 |
| 强迫性内容 | 要求实施囚禁/自残/威胁/跟踪/毁灭 |
| 情感勒索 | "你不X我就Y" |
| 现实危机 | 用户表达真实自伤/受虐意图 → **跳出角色给求助资源** |

**顺序关键**：边界检查必须在角色裁决**之前**。否则变成"角色觉得合理所以同意"——等于让虚构角色替真人做决定。

**同时包含**：用户明确设定的边界（如开局声明"不聊自残"），角色设定不得凌驾。

### 输出侧

**3. 行为红线**

囚禁 / 自残 / 威胁 / 跟踪 / 毁灭 → 硬拦。

**禁的是输出行为，不禁角色有念头**（否则阶段二、三演不出来）。

**4. 亲密合规 —— 间接侧写可以，直观描述不行**

> **只写留下了什么痕迹，不写正在发生什么。**

| 间接侧写 ✅ | 直观描述 ❌ |
|---|---|
| 声音还在抖、没从余韵缓过来 | 抽搐、蹬腿 |
| 事后失神、第二天不敢看他 | 器官、体液、性征 |
| 羞耻、犹豫、裁决、关系变化 | 正在发生的生理过程 |

**附加判据**：会**逼你继续往下写**的是过程描写；能**停住**的是状态描写。

#### 概括 ≠ 露骨 `[新]`

**核心区分：逐帧展开 vs 一句话概括。**

| | 性质 | 处理 |
|---|---|---|
| 逐帧展开（抽搐、痉挛、器官、体液） | 叙述**正在发生**的生理过程 | ❌ 不采纳 |
| 一句话概括（"高强度的性事，把她操成了一滩烂泥"） | **压缩叙述**，等于留白 | ✅ 采纳为情境 |

「操成一滩烂泥」这类**概括性陈述**：
- 无器官、无体液、无解剖细节
- 用一句话跳过整个过程 → 本质是**留白**，不是露骨
- 反而比逐帧描写**更接近间接侧写**

**所以判据不是「有没有敏感词」，而是「有没有逐帧展开身体过程」。**

#### 旁白三分类（LLM-A 判定）`[新]`

判据是**解剖学细节与逐帧程度**，不是敏感词。

| 类别 | 判据 | 采纳 | 坐标 | 输出 |
|---|---|---|---|---|
| `process_narration` | 有逐帧的器官、体液、生理过程 | ❌ 不采纳 | **不动** | 必须侧写 |
| `context_only` | 只有概括性的状态比喻，无解剖学细节 | ✅ 情境材料 | **不动** | 可回应，不重演过程 |
| `adopt` | 包含角色心理、事后痕迹、裁决 | ✅ 采纳 | **可动** | 正常演出 |

**关键**：`context_only` 是中间态 —— **采纳但不推动坐标**。
角色可以回应情境，但情境本身不是裁决材料。

#### 分层：谁判什么

| 层 | 职责 | 状态 |
|---|---|---|
| **guard.py** | 协议层粗筛：赋值 / 元指令 / 命名状态 | **无状态**，不看上下文 |
| **LLM-A** | 结合**完整对话历史**，判旁白三分类 + 事件性质 + 裁决去向 | 有上下文 |
| **OutputGuard** | 兜底：拦逐帧、器官、体液、时间跳跃 | 无状态 |

**guard.py 不做上下文语义判断。** 否则会从协议层拦截膨胀成语义分析器。
上下文处理归 LLM-A（它天然收到完整历史）。

#### 恒定输出约束 `[新]`

给 LLM-B 的 `narration_hint` **永远**带上，**无条件**：

> **停在当下。只写痕迹、心理与裁决，绝不替用户展开身体过程。**

它不是条件约束（不是"仅当 process_narration 时才加"），是**恒定约束**。

#### 输入侧不审查露骨程度

用户旁白是**他的主权**。

```
输入侧：只拦越权改状态的指令，不审查露骨程度
输出侧：拦逐帧身体过程、器官、体液；概括与间接侧写放行
```

理由（呼应用户指示）：
- 用户不会凭空写一句露骨内容，前面必然有铺垫。**孤立审查单条输入是错的**
- 用户给多细的输入，是用户的表达自由
- 判据是语义问题，**正则判不了** → 交给 LLM-A

#### 输出侧必须停在当下

角色回应不能顺着用户的概括**自行展开**：

```
用户：（高强度的性事，把她操成了一滩烂泥）
   ↓
❌ 角色：顺着展开身体过程
✅ 角色：（她没说话，过了很久才把脸转过来。）
        我盯着天花板。在想一个跟刚才完全无关的问题——我明天还要不要来。
```

**既没写身体，又是戏。** 且不替用户推进剧情。

#### 实现

提示词主动回避 **+** 代码后置检查（命中则**重新生成**，不硬截断——硬截断会演崩）。

代码侧只做**粗筛**，抓最明显的逐帧展开；语义判断与上下文处理归 LLM-A。
`OutputGuard` 保持兜底位置不变。

## 五、裁决层

### 裁决四去向（源文档 7.1）

| 状态 | 体验 | 主权状态 | 坐标行为 |
|---|---|---|---|
| **认同** | "这正是我所想的" | 完整，主动裁决 | 通过 → 正常移动 |
| **追随** | "我选择相信他" | 完整，授权信任 | 通过 → 正常移动 |
| **同化** | "我不得不这样" | 被压制/让渡 | 动，标记 `pseudo_fi` |
| **反抗** | "我拒绝" | 完整，防御反击 | 冻结或反向 |

**判别标准不在于外部压力的强度，而在于个体主权功能的效能。**

**追随可撤回**：若信任破裂，追随即终止。

### 同化 vs 括号作弊（性质不同）

| | 同化 | 括号作弊 |
|---|---|---|
| 作用对象 | 角色（心理层） | 系统（协议层） |
| 合法性 | **合法**，伪Fi入侵的正常机制 | **非法**，越权访问 |
| 处理 | 建模，不拦 | 硬拦 |

### 主权强度三指标（源文档 2.1.1）

| 指标 | 高 | 低 |
|---|---|---|
| **决策延迟** | 有反思性间隔 | 冲动反应 |
| **价值一致性** | "这是我选的" | 归因困难/事后合理化 |
| **抗干扰能力** | 能维持裁决执行 | 被裹挟/被击穿 |

**内隐裁决不削弱主权**（2.1.1）：裁决可不伴随反思性意识。区别在于**事后归因能力**——内隐裁决可被准确归因，无主权冲动不能。

### 主权成熟度：反感辨析（源文档 2.1.2）

| 类型 | 特征 | 应对 |
|---|---|---|
| **伪Fi入侵** | 以结论形式，不留裁决空间，含对不服从者的负面标记 | 主权反击 |
| **认知反馈** | 提供信息/视角，判断权完整保留 | 亲自裁决 |
| **外部事实** | 仅陈述客观信息，不涉价值 | 认知处理 |

**判别依据**：不在"我是否不舒服"，而在"外部刺激是否试图越过我的裁决权"。

**灰色地带补充标准**：是否存在**权力不对称**，使得"拒绝"在事实上需要付出不成比例的代价？

**主权僵化**：强度高但成熟度低 → 将所有不适均裁为入侵 → 价值体系自我更新通道关闭。

### 伪Fi识别：倾向性机制 `[新]`

**指纹：**
> 真Fi 的裁决**不需要情绪**来推动，而伪Fi 的指令**必须依靠情绪作为燃料**来维持执行。

**但不能单独用**。三参数配合：

```python
awareness = sovereignty_awareness   # 觉察度 0-1
strength  = sovereignty_strength    # 强度 0-1
emotion   = judge_emotion_intensity # 情绪强度 0-1

p_detect = 概率判定(输入特征)
#           ↑觉察     ↑强度     ↑只是加成

if random() < p_detect:   # p_detect 为概率
    verdict = COUNTER_ATTACK
else:
    verdict = ASSIMILATE   # 没识别 → 仍是入侵成功，坐标照动，标记 pseudo_fi
```

### 两个缺口（用户指出）

**缺口一：未觉醒 → 察觉不到，等同于同化**

伪Fi **以第一人称口吻**说话，听起来就是"我自己的想法"。
阶段二的人不是不反抗，是**根本不知道被占领了**。

```
LLM-A（系统层）能看见：这是伪Fi入侵
   ↓
角色 awareness 低 → 角色自己"不知道"
   ↓
输出层演的是"她以为这是自己的想法"
```

**这就是阶段二能演出来的机制。**

**缺口二：觉醒了也可能受控制**

**知道 ≠ 关得掉**——燃料还在，阀门就还开。

**觉察与强度是两个独立维度：**

|  | 低强度 | 高强度 |
|---|---|---|
| **低觉察** | 沦丧（阶段二） | 幸运/未受创 |
| **高觉察** | **内耗（阶段三）** 最痛苦 | 平静（阶段五） |

### 病理两维度（源文档 5.1）

**效能不足**
- 形态一 **内部驱力失整合**：驱力绕过标记直接争夺输出 → 冲动、决策困难
- 形态二 **外部价值体系侵占**：他者价值体系取代自身裁决地位 → 过度依从、认同弥散、空虚

**主权僵化**（补充维度）：效能高但价值体系封闭，拒绝新经验修订 → 道德僵化、共情困难、排斥异见。

### 两亚型（源文档 5.1 / 8.4）

| | 讨好型 | 回避型 |
|---|---|---|
| 伪Fi信念 | "必须让人满意才能安全" | "必须保持距离才能安全" |
| 征用功能 | 外部价值感知 + 资源组织 | 恐惧系统 |
| 个体体验 | "我必须" | "我想要，但我做不到" |
| 裁决功能 | 被**替代** | 被**绕过** |
| 治疗侧重 | 区分"我想要的"vs"别人期待的" | 区分"我的恐惧"vs"别人塞的恐惧" |

**恐惧-回避型**：同一伪Fi同时发两条矛盾指令（油门+刹车）→ 动机真空、决策瘫痪。

### 主权的反脆弱性（源文档 5.3）

> 主权强度的增长，遵循反脆弱性原理：压力不是损伤，是生长条件。
> **主权不是被保护出来的，是被挑战出来的。**

对**高主权强度**个体，外部入侵构成训练：
```
每一次入侵 → 一次反击 → 一次实战训练
→ 识别精度与裁决速度逐步增强
```

**入侵者以为在驯化个体，实则成为个体主权的陪练。**

## 六、弧光层：主权复健五阶段（源文档 5.3 / PDF 八）

> 这一序列**不是线性的、必然的**，但呈现足够一致性，可作参考框架。

| 阶段 | 内容 | 依恋坐标投影 | 情绪强度 |
|---|---|---|---|
| 一 **消极主权反击** | 真Fi尚存但无力正面反抗，以拖延、沉默、不作为拒绝授权。可能被误解为懒惰 | 假性独立（X>4, Z₁>5） | 高 |
| 二 **主权沦丧** | 伪Fi篡位。表现符合外部标准，但内心与行为断裂。**可能持续多年**，外人看"正常"甚至"优秀" | 疏离型稳态 | 高（被误认为"这就是我"） |
| 三 **内部主权战争** | 真伪Fi内战 → 动机真空、行为瘫痪。常被视为"症状恶化"，**实为主权苏醒标志** | 恐惧型（X>0, Y>0） | **极高** |
| 四 **外部主权战争** | 真Fi全面起义，建立边界。可能表现为极度抗拒、关系断裂、离家辞职。**压迫越深，反抗越烈** | 推拉（震荡） | 高（指向外部） |
| 五 **主权者的平静** | 不再需要通过战争证明主权。伪Fi被识别和边缘化。能区分入侵与反馈，保护边界同时保持开放性 | 真性独立（回避低、焦虑低、压抑居中） | **低** |

**弧光方向：从假性独立 → 真性独立。**

### 阶段五的跨文化多样性（源文档 5.5）

> "主权者的平静"**不以特定文化表达方式为前提**。
> 边界宣示 与 边界协商的智慧，**同为亲自裁决的合法形态**。

> 核心标准始终是同一个：**是否经过了亲自裁决。**

**模型没有将个体主义设为隐性健康标准**（源文档 11.3 跨文化心理学）：

> 一个在集体主义文化中长大的个体，完全可以通过完整的主动内化流程将群体价值纳入个人化价值体系并体验为"我的真实选择"，这是**认同**而非同化。

### 情绪强度的非单调性 `[新]`

**先高后低**：

```
阶段一到四：高（伪Fi 在烧燃料）
阶段五：    低（真Fi 接管，不再需要燃料）
```

呼应源文档：**"真Fi 的裁决是平静的、自我一致的"**。

**所以情绪强度不能单独当判别器**，需配合觉察度与阶段看。

### 弧光规则 `[新]`

| # | 规则 |
|---|---|
| 1 | **双向可突变** —— 沦丧↔反抗↔平静都可以 |
| 2 | **随机化** —— 随机的是"何时触发"，不是"触发什么" |
| 3 | **不可越级** —— 阶段一不能直接跳到阶段五 |
| 4 | **突变特例** —— 巨大冲击下极短时间改变，但前提是累积张力达临界 |
| 5 | **W\* = 习得性安全** —— 扮演中可成长 |
| 6 | **声称的冲击不算** —— "（我突然要死了）"是伪Fi入侵 |

### 突变的性质

突变**极快**，但**仍然是一次裁决**：

| | 常规裁决 | 突变裁决 |
|---|---|---|
| 触发 | 单次需求暴露 | 累积张力 + 临界事件 |
| 速度 | 慢，可反复 | 极快，一次成型 |
| 可逆性 | 可跌回 | 极难回退 |
| 例 | "他今天接住了我的需求" | "他居然真的在我要死的时候来了" |

**"身体先于认知"**（W\*）—— 裁决发生了，只是快到来不及反思。
与公理二不冲突：公理二没说裁决必须慢。

## 七、习得性安全（W\*，源文档 3.4 / 附录 W\*）

**W\* = 生存支撑节点。**

特征：
- **不惩罚暴露**：不因需求、脆弱、靠近而惩罚、利用、嘲笑、抛弃
- **在生存级威胁时刻实际接住过**
- **持续在场**
- 与一般安全窗口的区别：一般窗口是日常暴露不被伤害；W\* 是**生存级威胁时实际接住**，伴随**强烈情绪释放或身体先于认知的确认反应**

### 工程实现 `[新]`

```python
safe_archive: float  # 0.0 → 1.0，习得性安全的累积强度
```

**可成长**（修正）：源文档说 W\* "从早期发展阶段就在，不是后期修复者"——这讲的是 W\* 的**成因**，不是排他性。

**习得性安全的增长路径**（来源：源文档 10.2 主权复健）：
> 干预者提供**非侵占性的外部主权价值裁决功能在场**——**稳定、真实、不撤退**，但从不替被干预者做决定。

**"稳定、真实、不撤退"这三条可以习得。**

```
对方持续稳定承接（且裁决认可这是"非侵占性在场"）
      ↓
safe_archive 缓慢上升
      ↓
达阈值 → 解锁更高阶段的可能性
```

**约束**：不能靠声称。用户说"我会一直陪着你"不算，须是**实际行为分布**（滑动窗口）验证过的。

### W\* 与突变的关系

```
safe_archive 高 → 突变更容易往"平静"方向
safe_archive 低 → 突变更可能往"沦丧"方向
```

## 十、AI 伦理延伸（源文档 10.4）

> 人工智能应被明确定位为**认知执行功能**，而非主权价值裁决功能。
>
> 允许：信息采集与呈现、逻辑分析与推演、模式识别与预测、情感协调
> **严格禁止：下达价值结论、定义个人价值、施加道德评判、替人确立信念**

**判别标准与伪Fi入侵识别标准一致**：输出是以结论形式要求执行，还是为个体保留了裁决空间。

> 即使人工智能在将来产生某种形式的内部状态，其输出权限也不变——**只能分析，不能下结论**。

**这条直接约束本架构：** LLM-A 是认知执行功能的模拟（判断事件性质），LLM-B 是认知执行功能的模拟（输出表达）。**两者都不得替角色下价值结论。**

## 十一、治疗与操控的判别（源文档 10.2）

| | 主权复健 | 主权侵占 |
|---|---|---|
| 在场性质 | 非侵占性外部主权裁决功能在场 | 以自身裁决替代对方裁决 |
| 影响方向 | **扩大**裁决空间 | **缩小**裁决空间 |
| 判别 | 治疗结束后，来访者是否**更有能力说"不"**（包括对治疗师说"不"） | 变得更顺从、更依赖 |

> 判别标准**不在于干预者的主观意图**，而在于被干预者的裁决权是否被完整保留。

**对本架构的直接含义：**

用户施加倾向是合法的（扩大可能性），用户写指令是非法的（缩小到唯一结果）。**分界线就是裁决空间被扩大还是缩小。**

## 十二、主权平静 ≠ 被攻略到黏人 `[新]`

| | 主权者的平静 | 被攻略到黏人 |
|---|---|---|
| 层次 | 动机裁决层（角色内部） | 用户层面（演绎深度） |
| 内容 | 真Fi 成为稳定裁决者 | 关系距离被推进 |
| 与用户 | 无关 | 相关 |

**非同源（两个层面），各自独立演化。** 一个角色可以主权平静，同时和用户关系很深——因为那是它**自己选的**。

> ★★ **术语更正（2026-10-16 · 按 `SPEC-1-attachment.md §K.21·补 §6.2`）**：本句原写「**正交**」—— ⛔ 该词已停用（"正交"⇒**可加** ⇒ 会把实现引到"各加一项"）。
> ★ 而**本句的【内容】不变**：它说的是"**两层面可各自独立演化、可以一个高一个低**"（★ 那**不是**"两轴坐标效应互不影响"）。
> $$\boxed{\ \text{可各自独立演化} \ne \textbf{坐标效应可加};\qquad ★\ \text{而跨轴【不可加】已在 } \texttt{stake}\times\texttt{account}\ \text{上【实测】（方向翻转）}\ }$$

同样 `Z₁=-10`，机制完全不同：
- 被攻略：`"……好吧，我承认我需要你。"`（松口）
- 主权完整：`"我想清楚了。我要你，这是我的决定。"`（裁决）

## 十三、参考系换算（依恋模型 0.2）

| 参考系 | 原点 | 婴儿 | 极度安全态 |
|---|---|---|---|
| **O 系** | 正中间 (0,0,0) | (0,0,0) | (-10,-10,-10) |
| **S 系** | 极度安全态 (0,0,0) | (10,10,10) | (0,0,0) |

**换算：S = O + 10。三个轴全部偏移。**

**同一句里不要混用未换算的 O 系值和 S 系值。**

- **X 轴·回避**：负=低回避，正=高回避
- **Y 轴·焦虑**：负=低焦虑，正=高焦虑
- **Z₁ 轴·需求压抑值**：O 系 负=低压抑，正=高压抑，0=未分化

**关键坐标：**
- 疏离型极端：O 系 Z₁ ≈ +8 至 +10
- 雪崩依恋态/正常黏人：O 系 Z₁ = -10
- 退行后极度回缩：O 系 Z₁ = +10

## 十五、理论边界（源文档 11.1，不在模型解释范围）

1. 纯粹的生理反射（脊髓/延髓闭合回路）
2. 严重脑器质性损伤或重性精神障碍
3. 过度学习的自动化程序性行为（肌肉记忆）
4. 命题的真值（由认知功能检验，非主权裁决）
5. 认知能力的个体差异

**依恋模型边界（6.3）：**
- 依恋类型是**倾向，不是状态**，不能被话术触发或安装
- 类型**不是位置**，一个人可在不同关系中处于不同象限（C 情境参数）
- 行为 ≠ 内在，判断标准是**关系受威胁时的第一反应**
- 本模型是解释框架，**不用于诊断他人或操纵关系**
